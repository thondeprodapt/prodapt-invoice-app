# PRODAPT Invoice Studio

Open https://invoice.prodaptsolution.co.zw/ to use the app on a laptop or iPhone.

For iPhone use:

1. Open https://invoice.prodaptsolution.co.zw/ in Safari on the iPhone.
2. Tap Share, then Add to Home Screen. The app uses the PRODAPT logo as its icon.
3. Open the new PRODAPT icon and create a quotation, invoice or receipt.
4. Tap Share PDF, then choose WhatsApp or Mail/Gmail from the iPhone share sheet. The PDF is attached as a file. Download PDF is also available.

Data is saved in the browser on each device using local storage. Installing on an iPhone does not automatically copy records from the laptop. Use the app's backup export/import to move data, and keep a backup before clearing Safari/browser data.
